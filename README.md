# Study01_MNIST — 손글씨 숫자 인식

마우스로 숫자를 그리면 CNN이 실시간으로 알아맞히는 앱입니다. PyTorch로 MNIST를 학습하고, 데스크톱(tkinter)과 웹(자바스크립트) 두 가지로 쓸 수 있습니다.

**웹에서 바로 써 보기 → https://kyssky48.github.io/Study01_MNIST/**

설치 없이 브라우저에서 동작합니다. 그림은 서버로 전송되지 않고 브라우저 안에서만 계산됩니다.

**모든 코드와 주석이 한글로 작성되어 있습니다.** 함수명, 변수명, 클래스명까지 한글입니다.

```
┌─────────────────────┐
│  손글씨 숫자 인식    │
├─────────────────────┤
│                     │
│        ⌒            │
```

## 성능

| 항목 | 값 |
|---|---|
| MNIST 테스트 정확도 | **99.33%** (10,000장 중 9,933장) |
| 학습 조건 | 12 에폭, Adam, 데이터 증강 + StepLR |

## 사용법

학습된 가중치(`mnist_cnn.pt`)가 저장소에 포함되어 있어 바로 실행할 수 있습니다.

```bash
python draw_app.py
```

검은 캔버스에 숫자를 그리면 마우스 버튼을 떼는 순간 인식 결과가 나옵니다. **크고 두껍게** 그릴수록 잘 맞습니다.

### 직접 학습하기

```bash
python train.py              # 기본 12 에폭
python train.py --에폭 20    # 에폭 수 지정
```

MNIST 데이터셋을 `data/` 폴더에 자동으로 내려받습니다(약 64MB). 매 에폭 평가 후 **최고 정확도를 갱신했을 때만** `mnist_cnn.pt`를 덮어씁니다.

지원하는 인자: `--에폭` `--배치크기` `--평가배치크기` `--학습률` `--감쇠`

### 바탕화면 바로가기 (Windows)


바탕화면에 바로가기가 생성됩니다. `pythonw.exe`로 실행되므로 검은 콘솔 창이 뜨지 않습니다. 작업 표시줄에 고정하려면 바로가기를 작업 표시줄로 드래그하세요.

### 파이썬과 결과가 같은지 확인

[검증 페이지](https://kyssky48.github.io/Study01_MNIST/검증.html)를 열면 두 가지를 자동으로 확인합니다.

1. **모델 일치** — MNIST 테스트 이미지 50장을 넣어 PyTorch가 냈던 출력값과 비교. 예측은 전부 일치하고, 출력값 최대 오차는 약 6e-6(float32 누적 오차 수준)입니다.
2. **전체 경로** — 280×280 캔버스에 그린 뒤 전처리부터 추론까지 실제 사용 흐름대로 돌려 정답률 50/50.

## 모델 구조

```
입력 (1×28×28)
  → Conv2d(1→32, 3×3) + ReLU      26×26
  → Conv2d(32→64, 3×3) + ReLU     24×24
  → MaxPool2d(2)                  12×12
  → Dropout(0.25)
  → Linear(9216→128) + ReLU
  → Dropout(0.5)
  → Linear(128→10)
  → LogSoftmax
```

## 인식률을 높인 방법

### 데이터 증강

학습 데이터에만 `RandomAffine(회전 ±10°, 이동 10%, 확대축소 0.9~1.1)`을 적용했습니다. 평가 데이터에는 적용하지 않습니다. 매 에폭 조금씩 다른 글씨를 보게 되어, 손으로 그린 글씨의 크기·기울기 변화에 강해집니다. 증강 없이 3 에폭 학습했을 때는 98.90%였습니다.

### MNIST식 전처리

280×280 캔버스에 그린 그림을 MNIST와 같은 형식으로 맞춘 뒤 모델에 넣습니다.

1. 글씨가 있는 영역의 경계 상자를 잘라낸다
2. 비율을 유지한 채 긴 변을 20픽셀로 축소한다
3. 28×28 검은 바탕 가운데에 붙인다
4. 무게중심이 (13.5, 13.5)에 오도록 평행 이동한다

MNIST 자체가 이 방식으로 만들어진 데이터셋이라, 입력 형식을 맞춰 주어야 학습한 성능이 그대로 나옵니다.
