# Study01_MNIST — 손글씨 숫자 인식

마우스로 숫자를 그리면 CNN이 실시간으로 알아맞히는 데스크톱 앱입니다. PyTorch로 MNIST를 학습하고, tkinter 그림판으로 입력받습니다.

**모든 코드와 주석이 한글로 작성되어 있습니다.** 함수명, 변수명, 클래스명까지 한글입니다.

```
┌─────────────────────┐
│  손글씨 숫자 인식    │
├─────────────────────┤
│                     │
│        ⌒            │
│       ( 3 )         │   ← 마우스로 그리기
│        ⌡            │
│                     │
├─────────────────────┤
│  예측: 3  (99.8%)   │
│  3: 99.8%  8: 0.1%  │
├──────────┬──────────┤
│   인식   │  지우기  │
└──────────┴──────────┘
```

| 항목 | 값 |
|---|---|
| MNIST 테스트 정확도 | **99.33%** (10,000장 중 9,933장) |

## 모델 구조

```
입력 (1×28×28)
  → Conv2d(1→32, 3×3) + ReLU      26×26
  → Conv2d(32→64, 3×3) + ReLU     24×24
  → MaxPool2d(2)                  12×12
  → Dropout(0.25)
  → Linear(9216→128) + ReLU
  → Dropout(0.5)
  → Linear(128→10)
  → LogSoftmax
```

## 인식률을 높인 방법

### 데이터 증강

학습 데이터에만 `RandomAffine(회전 ±10°, 이동 10%, 확대축소 0.9~1.1)`을 적용했습니다. 평가 데이터에는 적용하지 않습니다. 매 에폭 조금씩 다른 글씨를 보게 되어, 손으로 그린 글씨의 크기·기울기 변화에 강해집니다. 증강 없이 3 에폭 학습했을 때는 98.90%였습니다.

### MNIST식 전처리

280×280 캔버스에 그린 그림을 MNIST와 같은 형식으로 맞춘 뒤 모델에 넣습니다.

1. 글씨가 있는 영역의 경계 상자를 잘라낸다
2. 비율을 유지한 채 긴 변을 20픽셀로 축소한다
3. 28×28 검은 바탕 가운데에 붙인다
4. 무게중심이 (13.5, 13.5)에 오도록 평행 이동한다

MNIST 자체가 이 방식으로 만들어진 데이터셋이라, 입력 형식을 맞춰 주어야 학습한 성능이 그대로 나옵니다.
